# reset 安全初始化头脑风暴

日期：2026-08-07  
状态：已批准并实现  
范围：只解决 `FormationEnv.reset()` 可能生成初始硬碰撞场景的问题；暂不处理 slot 分配、奖励结构、课程学习和碰撞几何模型升级。

## 1. 问题陈述

当前初始化将每艘拖轮独立、均匀地采样在大船中心半径
`tug_init_radius_m` 的圆上：

```text
angle_i ~ Uniform(0, 2π)
position_i = ship_center + radius · [cos(angle_i), sin(angle_i)]
```

默认大船长 200 m，圆环半径 100 m，恰好等于大船半长。采样不检查拖轮到大船碰撞船体的距离、任意两艇间距、参数组合是否有合法解，以及超过最大采样次数后的失败行为。

对当前默认配置的 5,000 个 seed 诊断结果为：

| 指标 | 比例 |
|---|---:|
| 至少一艘拖轮初始进入大船碰撞区 | 44.6% |
| 至少一对拖轮初始互相碰撞 | 33.5% |
| 任一类型初始碰撞 | 64.6% |

`reset()` 本身不报告碰撞，碰撞在第一次 `step()` 后才终止。这会产生与策略动作基本无关的终端惩罚，污染 rollout、回报和优势估计。

## 2. 目标与非目标

### 2.1 目标

建立以下 reset 后置条件：

1. 每艘拖轮满足初始船体间隙约束；
2. 每对拖轮满足初始最小间距约束；
3. 同一 seed 和配置得到完全相同的初始状态；
4. 采样失败不能静默返回非法场景；
5. 约束、尝试次数和失败信息可测试、可观测；
6. 正常配置下采样开销相对仿真可忽略。

### 2.2 非目标

本轮不顺带修改：

- `tug i → slot i` 的角色分配；
- 初始航向和速度；
- 课程学习；
- 碰撞检测是否升级为有朝向船体多边形；
- 奖励软安全距离与 slot 几何的冲突；
- 已失效的初始化可视化路线接口。

这些问题应另立设计，避免把“保证 reset 合法”扩大成训练任务重设计。

## 3. 安全语义候选

### S1：仅保证不触发当前硬碰撞

```text
d_hull(tug_i) >= ship_collision_dist_m
d_center(tug_i, tug_j) >= tug_collision_dist_m
```

优点：与当前终止条件完全一致，改动最小。  
缺点：缺乏数值和动态余量，第一步轻微运动即可碰撞。

### S2：硬阈值加初始化余量（建议）

```text
d_hull(tug_i) >= ship_collision_dist_m + init_ship_margin_m
d_center(tug_i, tug_j) >= tug_collision_dist_m + init_tug_margin_m
```

暂定起点：

```text
init_ship_margin_m = 5.0
init_tug_margin_m = 5.0
```

优点：仍以当前硬碰撞语义为准，同时吸收积分、船舶运动和浮点误差。  
缺点：余量是经验参数，需要根据第一秒碰撞率校准。

### S3：按真实拖轮外形留出空间

把拖轮 36 m × 11 m 的船体包络纳入约束，例如采用外接圆或有向矩形。

优点：物理意义最好。  
缺点：运行时仍使用点到大船矩形距离和拖轮中心距，reset 与 step 将采用两套碰撞语义。

当前建议选择 **S2**；S3 应与完整碰撞模型升级一起设计。

## 4. 空间分布候选

### D1：保留 100 m 精确圆环，条件拒绝采样

继续要求所有拖轮到大船中心的距离严格等于配置值，只接受满足安全约束的角度。

优点：最大程度保持旧配置数值。  
缺点：100 m 下船首尾附近不可接受，名义上的均匀圆环会变成偏向船舷的条件分布；更小半径可能无解。

### D2：提高默认圆环半径，再做安全拒绝采样（建议）

保留 `tug_init_radius_m` 的清晰语义，但把默认值提高到所有方向均可满足船体间隙的位置，拖轮间距通过拒绝采样保证。

一个简单保守的下界为：

```text
required_ship_clearance = ship_collision_dist_m + init_ship_margin_m
minimum_radius = hypot(ship_length_m / 2, ship_beam_m / 2)
               + required_ship_clearance
```

当前参数与 5 m 余量下，保守下界约为 112.1 m。

对每个半径各检查 1,000 个 seed，采用 S2 双余量和逐艇拒绝采样：

| 半径 | 满足船体间隙的角度比例 | reset 尝试数均值 / P95 | 零动作 1 秒碰撞率 |
|---:|---:|---:|---:|
| 100 m | 83.3% | 5.71 / 9 | 0% |
| 111 m | 87.6% | 5.31 / 8 | 0% |
| 115 m | 100% | 4.54 / 6 | 0% |
| 120 m | 100% | 4.51 / 6 | 0% |
| 130 m | 100% | 4.47 / 6 | 0% |

100 m 条件采样并不慢，但约 16.7% 的方向永远不会出现。115 m 已通过这次有限样本检查；**120 m** 比旧默认只增加 20 m，又比保守下界多约 8 m，当前建议作为 D2 的默认候选。

优点：语义简单、方向分布均匀、实现和测试容易。  
缺点：改变默认训练距离；需明确旧实验的兼容方式。

### D3：船体外等距环带

在大船碰撞船体膨胀后的外边界附近采样：

```text
clearance ~ Uniform(init_clearance_min_m, init_clearance_max_m)
position = point on expanded hull boundary
```

优点：所有方向的船体间隙更一致，大船尺寸变化时自然适配，长期物理语义最好。  
缺点：需要废弃或重新解释 `tug_init_radius_m`；“均匀”测度、迁移和实现成本最高。

### D4：中心极坐标安全环带

在 `[radius_min, radius_max]` 内采样半径，再执行安全拒绝采样。

优点：比单一半径更不易过拟合，仍容易理解。  
缺点：需要迁移配置；若内半径穿过船体仍有方向偏差。

当前建议：小步可靠修复选 **D2**；若准备长期重做初始化接口则选 D3。

## 5. 多艇采样候选

### A1：随机化顺序的逐艇拒绝采样（建议）

```text
accepted = []
order = random_permutation(agent_ids)
for tug_i in order:
    repeat up to bounded_attempts:
        candidate = sample_position()
        if ship_safe(candidate) and pairwise_safe(candidate, accepted):
            accepted.append(candidate)
            break
    else:
        fail loudly
```

优点：简单、高效、容易记录尝试次数；随机化顺序可减少 agent 编号偏差。  
缺点：分布不是严格的整组条件独立分布。

### A2：整组联合拒绝采样

每次生成所有拖轮，任一约束失败就丢弃整组。

优点：agent 交换对称，分布定义直接。  
缺点：拖轮增多或合法区域缩小时接受率快速下降。

### A3：分层角度采样

采样全局旋转角，让拖轮分处不同扇区，再加入有限扰动。

优点：天然保持艇间距，效率最好。  
缺点：减少近距离交通冲突多样性，明显改变当前分布。

### A4：Poisson-disk / dart throwing

把初始化区域视为二维最小间距采样问题。

优点：适合未来任意艇数和二维环带。  
缺点：对当前 4 艘固定圆环任务偏重。

当前建议：D2 配 **A1**；若选择 D3，则 A4 更自然。

## 6. 失败策略

所有随机采样必须有次数上限，避免无解配置令 reset 卡死。

### F1：超过上限明确报错（建议）

错误信息至少包含 seed、模式、半径/环带参数、安全阈值、已放置艇数和尝试次数。

优点：不静默改变任务，不混入非法场景。  
缺点：极低概率失败也会中断长训练，因此要通过压力测试设置合理上限。

### F2：确定性均匀角 fallback

优点：训练不中断。  
缺点：会静默改变分布；无解配置下 fallback 仍可能非法。

### F3：自动扩大半径

优点：最鲁棒。  
缺点：违反用户配置并破坏实验复现，不建议默认使用。

无论选择何种策略，都应先做可判定的静态参数检查；明显无解时立即失败。

## 7. 暂定实现骨架

1. `env/init.py` 增加无副作用的安全查询、配置验证和安全采样函数。
2. 在船体系或相对船中心坐标中生成候选点，再转换到世界系。
3. reset 与 step 复用同源碰撞几何查询，不复制船体距离公式。
4. reset 成功后执行显式后置条件检查，不依赖可被关闭的 `assert`。
5. 失败时抛出带诊断信息的 `InitializationError` 或 `RuntimeError`。
6. 不调用 `_check_termination()` 做初始化验证，因为它会修改 Capture/Track 状态。

暂定新增配置：

| 字段 | 暂定默认 | 含义 |
|---|---:|---|
| `tug_init_ship_margin_m` | 5.0 | 大船硬阈值外的初始化余量 |
| `tug_init_pair_margin_m` | 5.0 | 拖轮硬阈值外的初始化余量 |
| `tug_init_max_attempts` | 1,000 | 单次 reset 的有界尝试预算 |

若选择 D2，建议 `tug_init_radius_m=120.0`；若选择 D3，则以 clearance/环带字段替换或弃用 radius。

## 8. 可复现性与兼容性

- 拒绝采样会改变旧 seed 对应的具体场景，即使继续使用 100 m 半径。
- checkpoint 保存了完整 `env_cfg` 时应继续读取旧半径，但旧 100 m 是否允许条件采样需明确决定。
- 建议记录初始化 schema，避免不同采样器或角色分配器共享同一实验标签。
- 启动日志应打印最终模式、半径和安全阈值。
- legacy 模式若保留，只应用于历史复现，不应继续作为训练默认值。

## 9. 测试与验收

### 9.1 单元测试

1. 船首、船尾、船侧、角点附近的间隙边界；
2. 两艇距离位于阈值下、等于阈值和阈值上；
3. 固定 seed 重复 reset 完全一致；
4. 不可能配置在有限时间内抛出清晰错误；
5. 不同大船航向下，船体系分布一致；
6. `n_tugs=1`、默认 4 艘和更多拖轮；
7. 原半径契约测试按最终 D 方案更新。

### 9.2 统计诊断

至少检查 10,000 个 seed：

```text
initial_ship_collision_rate == 0
initial_tug_collision_rate == 0
sampling_failure_rate == 0  # 默认配置
```

同时输出尝试次数均值/P95/最大值、船体系角度直方图、船体间隙和最小艇间距分位数、到 slot 的初始距离分布。

分布统计不宜用过严的显著性断言阻塞普通 CI；CI 锁定安全不变量和宽松效率上界，完整分布检查放独立诊断脚本。

### 9.3 动态烟雾验收

额外记录零动作运行 1 秒的碰撞率：

```text
collision_within_1s_zero_action_rate
```

若明显非零，应增大初始化余量，而不是放松碰撞检测。

## 10. 风险

- 新旧训练曲线不能直接等价比较，必须记录初始化 schema。
- 只修 reset 不会解决奖励与目标几何的冲突。
- 余量过大会把任务变成纯远距追赶，减少近场避碰样本。
- 角度分层过强会让表面碰撞率下降，但避碰能力未必提高。
- 未来升级碰撞几何时，初始化必须复用新几何查询。

## 13. 后续：动态 slot 分配

安全采样落地后的复查发现，随机位置配合固定 `tug i → slot i` 会让团队总初始距离均值达到 628.3 m，且最难单艇平均距离为 226.9 m。后续已将默认分配改为 minimax：

1. 枚举唯一 slot 映射；
2. 首先最小化最远单艇初始直线距离；
3. 再最小化团队总距离；
4. 最后以 slot 字典序确定性消除平局。

匹配对象是匿名采样位置。环境随后按 slot 顺序把这些状态规范化到 canonical agent index，因此 actor 获得就近目标，同时 critic 仍可用 agent one-hot 表示固定角色，无需改变 global-state 维度。

5,000 seed 对比中，minimax 将团队总距离均值降至 349.7 m、最难单艇均值降至 153.0 m，至少一条直线路径穿过船体的 episode 比例由 83.7% 降至 15.8%。`fixed` 模式保留用于旧实验复现，schema 更新为 `safe_circle_v2`。
